This is the Adobe Offline Package downloader.

CHANGELOG

(0.3.1)
+ Added argument '--onlyWithSupportOS' for show only products supported on the specified macOS version
+ Added argument '--useSavedXML' for use previously downloaded products.xml
+ Added support for entering any numbers in the UrlVersion step
+ Changed folders structure
+ Added prevent continue when 0 products found

(0.3.0)
+ Added argument '--skipDependencyACR' and prompt for prevent downloading CameraRaw and remove this dependency from application.json and driver.xml
+ Added argument '--skipNonCorePackages' for skip downloading packages whose type is specified as non-core in application.json files and remove it from the file
+ Added argument '--skipModuleC4D' for skip downloading Cinema 4D packages and remove it from application.json files
+ Added argument '--skipModulesSpeechToText' for skip downloading Speech to Text packages and remove it from application.json files
+ Added argument '--removeCheckCompatibility' for remove point CheckCompatibility from SystemRequirement from application.json files
+ Added argument '--notWrapInApp' for just download adobe product to folder and not warp it into application
+ Fixed bug when downloading packages for not selected platform (when for macuniversal app downloaded macarm64 and osx10-64 packages but need only macarm64)

(0.2.1)
+ Added option to save products.xml with beautified version as local file
+ Added 'Accept-Encoding: gzip' for faster downloading products.xml
+ Added argument '--nativeOnly' for downloading only native packages for running platform
+ Added passing arguments from .command file to .py file

(0.2.0)
+ Added v5 & v6 URL (Support Photoshop BETA)
+ Added full support for Adobe Acrobat and partial support for XD (Need bearer_token)
+ Rewrote the code for parsing and downloading dependencies
+ Automatically uppercase SAP code and format language code

(0.1.4-hotfix1)
+ Updated URL (newer downloads work now)

(0.1.4)
+ Added M1 support. Defaults to yes when running on an M1 processor.
+ Added option to make another package after end.
+ Default picks picks newest version if one isn't specified
+ Default picks PhotoShop if nothing is entered, since it was used as the example.
+ Added Platform to version listing.

(0.1.3)
+ Went back to getting old URL.
+ Only show Versions actually Downloadable
+ Shows all Versions available

(0.1.2-hotfix1)
+ updated script to work with new api (newer downloads work now)
+ added workaround for broken installer on big sur
+ made everything even more messy and disgusting
